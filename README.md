   # Hospital Delivery Robot

   An autonomous indoor delivery robot built with ROS 2 Jazzy and Gazebo, demonstrated in a simulated hospital ward, with an Android (Kotlin + Jetpack Compose) staff app.

   ## Status
   - [x] Development environment set up (WSL2, ROS 2 Jazzy, Gazebo Harmonic)
   - [ ] ROS 2 fundamentals
   - [ ] Robot model (URDF)
   - [ ] Hospital ward world and navigation
   - [ ] Android staff app
   - [ ] Person detection
